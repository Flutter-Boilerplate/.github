# Flutter Boilerplate

Production-ready Flutter boilerplate templates to kickstart your next project.

## 🏢 Organization Repositories

| Repository               | Description                       | Link                                                                           |
| ------------------------ | --------------------------------- | ------------------------------------------------------------------------------ |
| **Base Boilerplate**     | Shared code and core utilities    | [View Repository](https://github.com/Flutter-Boilerplate/base-boilerplate)     |
| **Firebase Boilerplate** | Firebase-powered Flutter template | [View Repository](https://github.com/Flutter-Boilerplate/firebase-boilerplate) |
| **Supabase Boilerplate** | Supabase-powered Flutter template | [View Repository](https://github.com/Flutter-Boilerplate/supabase-boilerplate) |

### 🏗️ Architecture & Patterns

| Pattern                  | Description                        |
| ------------------------ | ---------------------------------- |
| **Clean Architecture**   | Data, Domain, Presentation layers  |
| **BLoC/Cubit**           | State management with flutter_bloc |
| **Dependency Injection** | GetIt for service locator          |
| **Immutable Models**     | Freezed for code generation        |
| **Navigation**           | GoRouter for declarative routing   |
